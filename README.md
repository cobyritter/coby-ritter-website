# Personal Website

This is a static personal website for Coby Ritter focused on his interest in investment banking and finance.

## Run locally

From the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Save and version it

This folder is set up as a Git repository so you can keep versions and return to earlier edits anytime.

```bash
git status
git add .
git commit -m "Initial site draft"
```

## Keep working later

Open this folder in VS Code, then continue editing the HTML, CSS, and JavaScript files.
